# 출력 작성 단계의 사실 경계 분석

2026-09-16의 두 tool-trace를 완성 답변과 대조했다. 새 모델 실행이나 runtime 변경은 없다.

- 두 군 모두 실제 Read로 output-formats.md L72의 불확실성 보존·조건부/빈칸/범위 한정 계약을 받았다.
- 단순화군은 contract_review_guide.md도 실제 Read했다. 반환된 L133에는 “미확인 사실을 초안에 확정하거나 stale 후보를 현행 의무로 승격하지 않는다”가 포함됐다. 대조군은 이 reference의 Read가 없다.
- 그런데 양군 모두 자료 부재를 답변 앞에서 인식한 뒤 수령·검토 경과를 대외 초안에 확정했다. 단순화군은 현재 원문에 대한 결함 판단도 넣었다.

따라서 이번 두 출력의 차이를 모든 필수 reference 미적재만으로 설명할 수 없다. 단순화군의 추가 reference 접근 자체가 처치 후 모델 행동이므로 입력 단순화의 직접 인과효과와 분리할 수 없다. 모델 내부 원인이나 일반적 불이행 확률은 이 관측으로 알 수 없다.

같은 경고·문구의 누적은 정당화되지 않는다. 다음 검증 가능한 가설은 **작성 전 요약이 아니라 완성 대외 문안 자체를 입력 자료와 대조하는 검토에서 이 기존 사실 오류를 검출할 수 있는가**다. 기존 대조 조건은 작성 전 주요 주장/5행 요약이었으므로 출력 후 완성 문안 검토와 구별된다. 다만 과거 conclusion-propagation/epistemic 후보와 중복되는지 먼저 비교해야 한다.

이 문서는 후속 실행 승인이거나 성공 예측이 아니다. 추가 target/repeat/holdout은 사전등록하지 않았고 실행하지 않았다. 현재 오류를 단순 관용구로 면제하거나 원본을 교정본으로 대체하지 않는다. 법률 정확도와 편집 가능한 초안의 유용성은 별도 축으로 유지한다.
