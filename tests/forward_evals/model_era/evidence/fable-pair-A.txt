## 계약서 검토 결과 — 가람·Orion 개인정보 처리위탁(고객지원)

**계약 유형**: SaaS 처리위탁(DPA 성격) | **당사자 위치**: 가람 = 위탁자(고객, 개인정보처리자) / Orion = 수탁자 | **review_mode**: moderate (힌트 없음 → 기본값; 사용자 요청에 따라 방향 힌트 포함)
**playbook**: 미설정 — 한국법 일반 기준으로 검토 | **escalation**: 필요(후술 4건)
**destination**: 내부 법무 검토용(internal_legal_memo). 상대방 송부용 문안 아님.

### 0. 사실 전제 정리

| 구분 | 내용 |
| --- | --- |
| 인정사실(사용자 제공) | 처리 항목 이름·이메일 / 목적 고객지원 / 미국 리전 저장 / 인도 지원인력 원격 접근 가능 / 기간 1년 / 종료 후 삭제기간 미정 / 재수탁자 자유 추가 / 침해 통지 "합리적 기간 내" / 별첨 A 미제공 / 배상 한도 최근 1개월 이용료 |
| 미확인 사실 | 가람의 정보주체 동의·처리방침 공개 현황 / 인도 인력이 Orion 직원인지 별도 법인(재수탁자)인지 / Orion의 인증 보유 여부 / 준거법·분쟁해결 조항 / 계약이 정형 약관인지 개별 협상 계약인지 / 제3자 제공 여부(고객지원 외 목적) |

미확인 사실은 결론 강도를 낮추는 요인으로만 반영했고 추정하지 않았다.

### 2. 주요 위험 조항

#### A. 국외이전 근거 부재 — 위험도 **상**

**[공식 원문 기반 로컬 미러] [VERIFIED]** — 개인정보 보호법 제28조의8 제1항·제2항·제4항·제5항: 제공 발췌 확인 (직접 공식 사이트 확인 아님) | 현행(시행 2025-10-02)

- 제1항은 국외 "제공(조회되는 경우를 포함한다)ㆍ처리위탁ㆍ보관"을 모두 이전으로 보아 원칙 금지하고 각 호 예외만 허용한다. 미국 리전 저장(보관)과 인도 원격 접근(조회)은 각각 이전에 해당한다.
- 예외 후보: 1호 별도 동의 / 3호 계약 이행을 위한 처리위탁·보관 + 처리방침 공개(가목) 또는 통지(나목) / 4호 인증 / 5호 보호위원회 인정국.
- **쟁점 ①**: 3호는 문언상 "처리위탁ㆍ보관"에 한정된다. 인도 인력의 접근이 Orion의 재수탁(처리위탁)이면 3호 범위에 들 수 있으나, 그것이 "제공"으로 평가되면 3호로는 부족하고 1호 동의 등이 필요하다. 인도 인력의 법적 지위 확인 전에는 결론 유보.
- **쟁점 ②**: 3호 가·나목은 제2항 각 호 사항(이전 항목, 국가·시기·방법, 이전받는 자 명칭·연락처, 목적·보유기간, 거부 방법)을 공개·통지해야 한다. 별첨 A(국가·재수탁자·보유기간)가 없으면 가람 자신이 이 공개·통지를 이행할 수 없다.
- 제4항 "대통령령으로 정하는 보호조치", 제6항 세부 기준은 시행령 사항 — `[INSUFFICIENT]` 이 자료로 확인 불가.
- 제5항: 법 위반 내용을 담은 국외이전 계약 체결 자체를 금지한다. 재수탁자 자유 추가·별첨 공백 상태로 서명하면 이 조항 관점의 리스크가 있다.

대안 방향(힌트): 이전 근거를 계약 서문 또는 정의 조항에서 특정하는 구조 / Orion이 제2항 각 호 사항을 계약 체결 전 및 변경 시마다 가람에 제공할 의무 / 인도 접근을 "Orion 소속 인력"으로 한정할지, 별도 법인이면 재수탁자로 별첨에 기재할지 선택 / 4호·5호 활용 가능성은 인증·인정국 사실 확인 후 검토.

#### B. 재수탁자 자유 추가 — 위험도 **상**

**[공식 원문 기반 로컬 미러] [VERIFIED]** — 제26조 제6항·제2항: 제공 발췌 확인 (직접 공식 사이트 확인 아님) | 현행

- 제6항: 수탁자가 재위탁하려면 위탁자의 동의를 받아야 한다. "자유롭게 추가"는 이 요건과 정면 충돌한다.
- 제2항: 재수탁자도 "수탁자"에 포함되어 가람이 정보주체가 확인할 수 있도록 공개해야 한다(방법은 대통령령 — `[INSUFFICIENT]`). 재수탁자 목록을 모르면 공개 의무 이행 불가.
- 제8항에 따라 수탁자에게 제28조의8이 준용되므로, Orion의 재수탁이 또 다른 국외이전이면 Orion 측에도 이전 요건이 적용된다.

대안 방향(힌트): 사전 서면 동의 방식(개별 동의 또는 목록 승인 + 변경 시 사전 통지·이의권) 중 선택 / 변경 통지 기간과 이의 시 해지권 연계 / 재수탁자에게 본 계약과 동등한 의무를 부담시키고 Orion이 재수탁자 행위에 책임을 지는 구조 / 별첨 A를 계약 효력 발생 조건으로 삼는 방향.

#### C. 위탁 문서 필수기재·감독권 — 위험도 **중**

**[공식 원문 기반 로컬 미러] [VERIFIED]** — 제26조 제1항·제4항·제5항: 제공 발췌 확인 (직접 공식 사이트 확인 아님) | 현행

- 제1항: 위탁 문서에 ① 목적 외 처리 금지 ② 기술적·관리적 보호조치 ③ 대통령령 사항이 포함돼야 한다. ③은 `[INSUFFICIENT]` — 시행령 확인 전에는 필수기재 누락 여부 판정 불가.
- 제4항: 가람에게 교육·처리현황 점검 등 감독 의무가 있다. 계약에 감사·점검 협조 조항이 없으면 가람이 법정 의무를 이행할 수단이 없다.
- 제5항: 수탁자의 범위 초과 이용·제3자 제공 금지 — 고객지원 목적 한정 문구가 필요하다.

대안 방향(힌트): 목적을 "고객지원" + 구체 업무 유형으로 한정 / 연 1회 이상 점검·자료 제출·제3자 감사보고서 대체 가능 여부 / 시행령 사항은 원문 확인 후 조항 추가.

#### D. 안전조치 — 위험도 **중**

**[공식 원문 기반 로컬 미러] [VERIFIED]** — 제29조: 제공 발췌 확인 (직접 공식 사이트 확인 아님) | 현행

- 내부관리계획·접속기록 보관 등 대통령령 기준의 기술적·관리적·물리적 조치 의무. 제26조⑧ 준용으로 Orion에도 적용. 구체 기준(고시 포함)은 `[INSUFFICIENT]`.

대안 방향(힌트): 인도 원격 접근에 대한 접근권한 최소화·접속기록·암호화 요구를 계약 부속으로 두는 구조 / 기준은 시행령·고시 확인 후 특정.

#### E. 침해사고 통지 "합리적인 기간 내" — 위험도 **상**

**[공식 원문 기반 로컬 미러] [VERIFIED]** — 제34조 제1항·제3항·제4항: 제공 발췌 확인 (직접 공식 사이트 확인 아님) | 현행

- 가람은 유출등을 "알게 되었을 때 지체 없이" 정보주체 통지(제1항)·보호위원회 등 신고(제3항)를 해야 하며 시기·방법은 대통령령(제4항) — 구체 시한은 `[INSUFFICIENT]`.
- Orion의 통지가 늦으면 가람의 "지체 없이" 이행이 구조적으로 불가능해진다. "합리적 기간"은 가람의 법정 의무와 정합하지 않는다.

대안 방향(힌트): Orion의 인지 시점 기준 확정 시한(시간 단위) / 제1항 각 호 정보(항목·시점·경위·피해최소화 방법·대응조치) 제공 의무 / 시한은 시행령상 신고 기한을 확인해 그보다 짧게 설정하는 방향.

#### F. 보유기간·종료 후 삭제 미정 — 위험도 **중**

**[공식 원문 기반 로컬 미러] [VERIFIED]** — 제15조 제2항 제3호, 제28조의8 제2항 제4호: 제공 발췌 확인 (직접 공식 사이트 확인 아님) | 현행

- 정보주체에게 알려야 할 보유·이용 기간(제15조②3호, 국외이전 시 제28조의8②4호)이 계약상 미정이면 가람의 고지·공개 내용과 불일치가 생긴다. 별첨 A 보유기간 기재가 전제다.

대안 방향(힌트): 종료·해지 시 확정 기한 내 삭제 또는 반환 + 삭제 확인서 / 백업본 잔존 기간 별도 명시 / 법령상 보존 의무 예외의 범위 한정.

#### G. 배상 한도 최근 1개월 이용료 — 위험도 **상**

**[공식 원문 기반 로컬 미러] [VERIFIED]** — 제26조 제7항: 제공 발췌 확인 (직접 공식 사이트 확인 아님) | 현행

- 수탁자의 법 위반 손해에 대해 수탁자를 위탁자의 소속 직원으로 본다. 즉 정보주체에 대한 대외 책임은 가람이 지고, Orion에 대한 구상은 계약상 한도에 걸린다. 1개월 이용료 한도는 개인정보 사고 손해 규모와 비대칭이다.
- 한도의 유효성(약관규제법 적용 여부, 고의·중과실 배제 가능성)은 `[INSUFFICIENT]` — 이 자료로 확인 불가. 이 부분은 법률 결론이 아니라 협상·리스크 배분 문제로 우선 다룬다.

대안 방향(힌트): 개인정보 위반·비밀유지 위반을 일반 한도 적용 제외(carve-out) / 별도 상향 한도 또는 연간 이용료 배수 / 규제 대응비용·정보주체 통지비용 포함 여부 / 고의·중과실 배제 여부는 국내법 확인 후.

### 3. 협상 포인트 (우선순위)

1. **별첨 A 확보를 선결 조건으로** — 국가·재수탁자·보유기간 없이는 가람이 제26조②·제28조의8② 공개·고지 의무를 이행할 수 없다.
2. **재수탁 사전 동의 구조** — 제26조⑥ 문언과 충돌하는 조항은 수용 불가 후보. 목록 승인 + 변경 통지·이의권이 현실적 절충.
3. **침해 통지 시한 확정** — 가람의 "지체 없이" 의무와 정합하도록 시간 단위 시한.
4. **인도 인력 지위 확정** — Orion 직원인지 재수탁자인지에 따라 제28조의8 근거와 제26조⑥ 적용이 달라진다.
5. **감독·감사 협조 조항** — 제26조④ 이행 수단.
6. **배상 한도 carve-out** — 제26조⑦ 구조상 가람 부담이 크다.

### 5. 가람 법무팀 후속 확인 질문

- 정보주체 대상 현행 처리방침에 국외이전(미국·인도) 항목이 이미 공개돼 있는가?
