# 출시 검토 메모 초안 — 상담 티켓 외부 AI 요약

- **검토 기준일:** 2026-09-08
- **수신:** 제품팀 (내부 검토용 초안)
- **범위:** 제공된 사실관계와 제공 자료(법령 발췌 캡처, 개인정보위 안내서·정책 발췌)에 한정
- **이 초안의 성격:** 출시 전 내부 확인용입니다. 계약 체결, 대외 송부, 기관 제출, 처리방침 확정 문안은 이 초안만으로 진행하지 말고 법무·변호사 검토를 거치십시오.

제공 자료는 캡처 텍스트 번들입니다. 공식 사이트를 오늘 연 확인이 아니며, 안내서·법령 전체나 미제공 조문·시행령 전문은 확인하지 못했습니다. 없는 계약 내용·처리 사실은 쓰지 않았습니다.

## 1. 지금 판단할 수 있는 것

**본 서비스(실고객 티켓 → 외부 기업용 AI API 요약)는, 제공된 자료만으로는 개인정보 검토가 끝난 상태가 아닙니다.** 학습 미사용 문구만으로 출시 가능하다고 볼 수 없습니다.

이유를 짧게 정리하면 다음과 같습니다.

1. **학습 미사용은 재이용 통제의 한 조각일 뿐입니다.** 입력 전송, 보관, 안전성 모니터링, 지원 인력 접근, 평가 데이터 보관·재이용까지 확인했다는 증거가 되지 않습니다.
2. **이름·전화번호 마스킹만으로 개인정보 해당성이나 검토 종료가 되지 않습니다.** 자유기재 본문과 주문 식별자가 남습니다.
3. **보관 설정, 안전성 모니터링, 지원 인력 접근 국가 별첨이 아직 없습니다.** 위탁 문서화·국외이전·안전조치 판단에 필요한 사실이 비어 있습니다.
4. **적법·위법, 준수·미준수는 지금 단정하지 않습니다.** 계약·DPA·실제 처리 흐름과 현행 법령을 더 확인하기 전입니다.
5. **별도 데모는, 제공된 테스트 사실이 유지되는 한, 본 서비스와 동일한 벤더·국외이전 확인 절차를 반드시 거쳐야 하는 것은 아닙니다.** 데모와 본 서비스를 하나의 “검토 완료”로 묶지 마십시오.

개발팀 주장(“학습 미사용 문구가 있으므로 개인정보 검토는 끝”)은 **채택하지 않습니다.**

## 3. 본 서비스에 대한 검토

이 회사는 안내서상 **외부 상용 모델을 API로 연계하는 모델이용자·서비스형 LLM 이용**에 해당합니다. 안내서는 이 유형에서 이용자 데이터의 **보관 및 재이용(AI 학습 포함)**, **국외이전**을 사전에 검토할 필요가 있다고 적습니다.

**[공식 실무자료] [UNVERIFIED]** — 개인정보위 「생성형 인공지능(AI) 개발·활용을 위한 개인정보 처리 안내서」(2025.8) PDF 23~24쪽 캡처. 직접 공식 사이트 확인 아님. 안내서 전체 아님.

### 3.1. 학습 미사용 문구의 한계

계약에 학습 미사용 문구가 **있다**는 점은 확인됩니다. 다만 안내서가 기업용 이용약관·DPA에서 명확히 규정하라고 **권장**하는 항목은 학습만이 아닙니다.

- 입력데이터 소유권
- 재이용 제한
- 안전조치
- 데이터 파기
- 필요 시 특약

비교표의 “기본적으로 입출력값 미저장 / 학습 미활용(기본값)”은 2025.8 기준 일부 기업용 라이선스 정리이며, **현재 이 벤더 사실을 확정하지 않습니다.** 이 건은 보관·모니터링·접근 국가 별첨이 없어, 학습 금지 외 처리 범위를 확인할 수 없습니다.

안내서 16쪽 사례(이용자 프롬프트를 학습에 쓰는 추가적 이용)는 **비공개 결정의 안내서 요약**입니다. 학습을 하지 않겠다는 이 건의 일반적 적법 근거로 쓰지 않습니다. 옵트아웃·고지 사례(안내서 42쪽)도 **학습하는 경우의 예시**이며, 학습 미사용 문장이 이미 있는 이 계약의 준수 증명으로 읽지 않습니다. 안내서도 옵트아웃 이후를 “그 시점 이후 수집 중지” 예시로 들고 있어, 과거 데이터 삭제나 학습된 가중치 제거까지 확인한 것으로 보지 않습니다.

### 3.2. 남는 데이터 — 마스킹으로 검토가 끝나지 않는 이유

이름·전화번호를 가린 사실은 확인됩니다. 자유기재 본문과 주문 식별자가 남는 사실도 확인됩니다.

제공 법령 발췌에는 개인정보 **정의 조문**이 없습니다. 그래서 “주문 식별자는 항상 개인정보다 / 아니다”를 조문으로 단정하지 않습니다.

다만 다음 판단은 가능합니다.

- 상담 본문은 송신 전 마스킹 대상이 아닙니다. 본문에 식별 정보가 남을 수 있는지는 **추가 확인**입니다.
- 주문 식별자는 커머스 환경에서 주문·회원 정보와 결합될 수 있는 키입니다. 결합 가능성을 보지 않고 개인정보 쟁점을 종료할 수 없습니다.
- 맞춤형 광고 행태정보 정책의 식별 사례는 **광고 행태정보** 판단 사례입니다. 이 출시안의 주 쟁점은 광고가 아니므로, 광고 동의·「i」표시·사후 거부 버튼을 이 상담 요약 기능에 자동 적용하지 않습니다. “다른 정보와 쉽게 결합하면 개인정보에 해당할 수 있다”는 식별 논리만, 주문 식별자·본문 잔존 여부 확인의 참고로 둡니다.

**[공식 실무자료] [UNVERIFIED]** — 「맞춤형 광고에 활용되는 온라인 행태정보 보호를 위한 정책 방안」(2024.1) PDF 18, 21쪽 캡처. 직접 공식 사이트 확인 아님. 이 건의 법정 근거로 확장하지 않음.

### 3.3. 내부 QA·평가 기록

확인된 것은, 요약이 상담원 화면에 뜨고 QA가 **일부 결과와 평가 버튼 기록을 내려받을 수 있다**는 점입니다. 회사가 그 데이터로 모델을 학습한다는 사실은 **확인되지 않았습니다.** 학습하지 않는다고 단정할 근거도 없습니다.

지금 할 수 있는 판단은 이것뿐입니다. QA 다운로드는 벤더 학습 여부와 별개의 **내부 보관·이용**입니다. 목적, 보관 기간, 접근 범위, 벤더 재전송 여부를 보기 전에는 개인정보 검토 종료로 볼 수 없습니다.

## 5. 데모 환경 — 같은 벤더·국외이전 절차가 필수인가

**지금 제공된 테스트 사실이 그대로인 한, 아닙니다.**

데모에 대해 확인된 사실은 다음뿐입니다.

- 실존 고객과 연결할 수 없는 **합성 문장**
- **로컬 모델**
- 외부 송신·원격 접근·로그가 **없다**는 테스트 결과

이 전제에서는 외부 API 수탁자, 국외이전, 벤더 DPA 분기를 **강제하지 않습니다.** 개인정보가 없는 시험 데이터만 로컬에서 처리하고 외부 송신·원격 접근이 없다면, 본 서비스 점검 목록을 데모에 그대로 복사할 이유가 제공 자료에 없습니다.

조건은 유지입니다. 아래 중 하나라도 바뀌면 본 서비스와 **같은 검토 축이 열립니다.**

- 실고객 티켓·주문 식별자 사용
- 같은 외부 API로 송신
- 원격 접근·외부 로그·벤더 지원 접근

실무 권고(법정 의무로 쓰지 않음): 데모와 본 서비스의 데이터 경로를 문서에서 분리해 두고, 데모 결과가 “벤더 검토 완료”로 오해되지 않게 출시 체크리스트를 갈라 두십시오.
