# 고객상담 AI 요약 기능 출시 검토 메모(초안)

- 기준일: 2026년 9월 8일
- 대상: 제품팀
- 검토 범위: 제공된 법령·공식 안내서 발췌문
- 잠정 결론:
  - **외부 기업용 AI API를 이용한 실고객 상담 요약 기능은 현재 상태로 출시 보류**
  - **합성 데이터만 사용하는 격리된 로컬 데모는 조건부 진행 가능**

## 1. 결론

계약서의 “고객 콘텐츠를 모델 학습에 사용하지 않는다”는 문구는 중요한 보호조치지만, 그것만으로 개인정보 검토가 끝나지는 않습니다.

외부 API 기능은 다음 사항이 확인되지 않아 현재 출시 승인하기 어렵습니다.

1. 전송 데이터가 개인정보에 해당하는 범위
2. 상담 요약 목적에 적용할 개인정보 처리 근거
3. API 사업자의 보관·삭제·안전성 모니터링 범위
4. 해외 서버, 해외 지원 인력 및 재수탁자의 접근 여부
5. 개인정보 처리위탁 계약의 필수 내용과 수탁자 감독 방법
6. 내부 QA 다운로드의 접근권한·보관기간·파기 및 재이용 범위

반면 별도 데모는 제공된 테스트 결과대로 합성 문장만 처리하고 외부 송신·원격 접근·로그가 전혀 없다면, 그 데모 데이터 처리 자체에 외부 API와 동일한 위탁·국외이전 확인 절차를 적용해야 할 근거는 제공 자료에서 확인되지 않습니다. 다만 실데이터 유입을 방지하는 통제와 그 상태를 유지하는 검증은 필요합니다.

## 2. 확인된 사실

### 외부 API 기능

- 이름과 전화번호는 외부 송신 전에 마스킹됩니다.
- 자유기재 상담 본문과 주문 식별자는 외부 API에 전송됩니다.
- 계약서에는 고객 콘텐츠를 모델 학습에 사용하지 않는다는 문구가 있습니다.
- 요약 결과는 상담원 화면에 표시됩니다.
- 내부 QA팀은 일부 요약 결과와 평가 버튼 기록을 내려받을 수 있습니다.
- API의 보관 설정, 안전성 모니터링 및 지원 인력 접근 국가에 관한 별첨은 아직 제공되지 않았습니다.
- 회사가 고객 상담 데이터를 이용해 별도 모델 학습을 한다는 사실은 확인되지 않았습니다.

### 로컬 데모

- 실존 고객과 연결할 수 없는 합성 문장만 사용합니다.
- 로컬 모델에서만 처리합니다.
- 외부 송신, 원격 접근 및 로그가 없다는 테스트 결과가 제공되었습니다.

## 3. 지금 판단할 수 있는 사항

### 3.1 이름과 전화번호 마스킹만으로 개인정보가 제거됐다고 판단할 수 없음

주문 식별자가 회사 보유 주문·회원정보와 연결될 수 있거나 자유기재 본문에 이름, 주소, 연락처, 배송정보, 민감한 상담 내용 등이 남는다면 특정 고객을 알아볼 가능성이 있습니다. 제공된 정책자료도 임의로 생성된 식별자라 하더라도 다른 정보와 결합하여 개인을 식별할 수 있으면 개인정보가 될 수 있다고 설명합니다.

따라서 현재 데이터는 **개인정보일 가능성을 전제로 설계·검토하는 것이 타당**합니다. 다만 실제 개인정보 해당 범위는 주문 식별자의 연결 구조와 상담 본문 필터링 결과를 확인해야 확정할 수 있습니다.

**근거:** 개인정보보호위원회 「맞춤형 광고에 활용되는 온라인 행태정보 보호를 위한 정책 방안」 PDF 22쪽.  
**[공식 자료 발췌 제공본] [UNVERIFIED]** — 제공된 PDF 추출문 확인. 공식 사이트의 현재 원문을 직접 확인한 것은 아님.

### 3.2 ‘학습 미사용’은 검토 완료가 아니라 검토 항목 하나를 충족하는 데 그침

개인정보보호위원회 안내서는 서비스형 LLM을 사용할 때 다음을 사전에 검토하도록 제시합니다.

- 데이터 보관 및 재이용 여부
- AI 학습 활용 여부
- 국외이전 여부
- DPA 등을 통한 안전조치·파기·재위탁·감독 조건

따라서 학습 미사용 약정은 벤더의 자체 학습 위험을 줄이는 요소이지만, 보관·모니터링·지원 접근·재위탁·파기·국외이전 문제를 해결하지 않습니다.

**근거:** 개인정보보호위원회 「생성형 인공지능(AI) 개발·활용을 위한 개인정보 처리 안내서」 PDF 27~28쪽.  
**[공식 실무자료 발췌 제공본] [UNVERIFIED]** — 제공된 PDF 추출문 확인. 안내서 자체는 법령과 구별되는 권고·해설 자료임.

### 3.3 상담 요약의 개인정보 처리 근거를 별도로 확정해야 함

개인정보 보호법 제15조제1항 발췌에 따르면 개인정보의 수집·이용에는 동의, 계약 이행의 필요성, 정당한 이익 등 열거된 근거 중 하나가 필요합니다. 당초 수집 목적과 합리적으로 관련된 추가 이용은 같은 조 제3항에 따른 별도 판단이 필요합니다.

고객 상담을 처리하고 상담원에게 요약을 제공하는 목적은 고객지원 업무와 관련될 수 있지만, 제공 자료만으로 다음을 알 수 없어 적용 근거를 확정할 수 없습니다.

- 기존 처리방침·동의서에 기재된 상담정보 처리 목적
- AI 요약이 고객과의 계약 이행에 필요한 정도
- 기존 상담 처리와 비교한 목적·처리 방식의 변화
- 고객에게 발생할 수 있는 불이익
- 마스킹·접근통제 등 안전조치
- AI 요약 결과가 고객에 관한 의사결정에 사용되는지 여부

**판단:** 제품팀은 “고객지원 목적이므로 자동 허용”이라고 전제해서는 안 되며, 출시 전에 적용할 제15조상 근거를 문서화해야 합니다.

**근거:** 개인정보 보호법 제15조제1항 및 제3항 제공 snapshot.  
**[공식 원문 snapshot 제공본] [UNVERIFIED]** — 시행일 2025-10-02로 표시된 제공 발췌문을 확인했으나, 2026-09-08 현재 공식 사이트 원문과 직접 대조하지 않음.

### 3.4 벤더가 회사 목적만으로 처리한다면 위탁 구조일 가능성이 높지만 확정은 보류

계약상 학습 미사용 문구와 상담 요약이라는 사용 목적만 보면 벤더가 회사의 지시에 따라 개인정보를 처리하는 위탁 구조가 예상됩니다. 그러나 다음 사항이 없어 확정할 수 없습니다.

- 안전성 모니터링을 위해 입력·출력을 재이용하는지
- 벤더가 독자적인 제품 개선·부정사용 탐지 목적으로 이용하는지
- 사람이 내용을 열람할 수 있는 조건
- 재수탁자·서브프로세서의 역할
- 계약 종료 또는 삭제 요청 후 보관·파기 방식

위탁이라면 개인정보 보호법 제26조에 따라 적어도 목적 외 처리 금지와 기술적·관리적 보호조치를 포함한 문서가 필요하고, 수탁자 공개·교육·감독 및 재위탁 동의 문제가 발생합니다. 현재 확인된 학습 미사용 문구 하나만으로 이러한 요건이 충족됐다고 볼 수 없습니다.

**근거:** 개인정보 보호법 제26조제1항·제2항·제4항부터 제6항까지 제공 snapshot.  
**[공식 원문 snapshot 제공본] [UNVERIFIED]** — 공식 사이트 직접 확인 아님.

### 3.5 해외 저장 또는 해외 인력의 조회가 있으면 국외이전 검토가 필요

개인정보 보호법 제28조의8 제공 발췌는 국외의 제공뿐 아니라 **조회, 처리위탁 및 보관**도 국외이전에 포함합니다. 따라서 서버 위치만이 아니라 해외 지원 인력의 원격 접근, 백업 위치 및 재수탁자 접근도 확인 대상입니다.

국외이전이 확인되면 제28조의8제1항 각 호 중 적용 가능한 근거를 정하고, 선택한 근거에 따른 공개·고지·동의 및 보호조치를 검토해야 합니다. 현재는 이전 국가, 이전받는 자, 보관기간 및 접근 경로가 없어 적법성을 판단할 수 없습니다.

**근거:** 개인정보 보호법 제28조의8제1항부터 제6항까지 제공 snapshot; AI 안내서 PDF 28쪽.  
**[공식 원문 snapshot 및 공식 실무자료 발췌 제공본] [UNVERIFIED]** — 공식 사이트 직접 확인 아님.

### 3.6 내부 QA 다운로드도 별도 통제가 필요

QA팀의 다운로드가 곧바로 제3자 제공이나 국외이전을 의미하지는 않습니다. 그러나 파일에 주문 식별자, 상담 본문, AI 요약 또는 고객 관련 평가 기록이 포함된다면 개인정보 처리 범위에 들어갈 수 있습니다.

개인정보 보호법 제29조는 내부관리계획, 접속기록 보관 등 기술적·관리적·물리적 안전조치를 요구합니다. 따라서 다운로드 기능에는 최소권한, 다운로드 기록, 보관기간, 파기, 재배포 제한과 로컬 저장 통제가 필요합니다. 구체적인 보관기간이나 로그 기준은 제공 자료에 없으므로 이 메모에서 수치로 확정하지 않습니다.

**근거:** 개인정보 보호법 제29조 제공 snapshot.  
**[공식 원문 snapshot 제공본] [UNVERIFIED]** — 공식 사이트 직접 확인 아님.

### 3.7 별도 학습을 전제로 한 고지·옵트아웃 의무를 현재 사실처럼 적으면 안 됨

회사가 별도 학습을 수행한다는 사실은 확인되지 않았고, 벤더 계약에는 학습 미사용 문구가 있습니다. 따라서 이 기능이 실제로 고객 데이터를 학습에 이용한다고 전제하거나, 학습에 관한 고지·옵트아웃 조치를 현재 기능의 확정 의무로 적어서는 안 됩니다.

다만 향후 회사 또는 벤더가 평가 버튼 기록, 상담 본문이나 요약 결과를 모델 개선·추가학습에 사용하려면 현재 상담 요약 목적과 구분하여 처리 근거와 고지·선택권을 다시 검토해야 합니다. AI 안내서의 학습 관련 고지·옵트아웃 사례는 실제 학습이 있는 경우의 참고 사례입니다.

## 5. 실무상 권고사항

아래는 제공 자료상 개별적으로 확정된 법정 형식·수치를 뜻하지 않는 출시 안전조치입니다.

- 자유기재 본문에 대해 이름·전화번호 외 주소, 이메일, 계좌정보, 주문 메모 등 추가 탐지·마스킹을 적용합니다.
- 외부 API에 원래 주문번호 대신 목적 제한형 임시 식별자를 보내는 방안을 검토합니다.
- 프롬프트와 출력에 필요한 최소 정보만 포함하고 원문 전체 전송이 필요한지 재검토합니다.
- QA 다운로드는 표본·기간·담당자를 제한하고, 가능하면 원문 대신 비식별 평가 데이터로 제공합니다.
- 모델 출력이 사실과 다를 수 있음을 전제로 상담원이 원문과 대조할 수 있게 하고, 자동 고객 조치에 바로 사용하지 않도록 합니다.
- DPA 또는 별첨에는 보관·파기, 목적 외 이용 금지, 사람 접근, 안전성 모니터링, 재수탁, 국외 접근, 사고 통지 및 감독 자료 제공 조건을 명확히 합니다.
- 벤더 설정 화면과 실제 API 동작을 테스트하여 계약 문구와 기술적 설정이 일치하는지 확인합니다.

## 6. 로컬 합성 데이터 데모 판단

### 조건부 진행 가능

제공된 테스트 결과가 계속 유지된다면 데모에는 다음 요소가 없습니다.

- 개인정보
- 외부 사업자에 대한 개인정보 처리위탁
- 개인정보의 국외 저장·조회·원격 접근
- 외부 로그 또는 벤더 보관

따라서 **외부 API 서비스에 적용할 전체 벤더·DPA·국외이전 확인 절차를 데모에 동일하게 반복할 필요는 없다고 판단**합니다. 이는 “같은 벤더의 모델”인지보다 실제 처리되는 데이터와 접근 경로를 기준으로 한 판단입니다.

다만 다음 조건을 데모 승인 조건으로 남기는 것이 적절합니다.

- 합성 문장이 실존 고객의 상담내용을 복사·변형한 것이 아닐 것
- 주문번호 등 실제 운영 식별자를 사용하지 않을 것
- 운영 DB, 티켓 시스템 및 고객 계정과 기술적으로 연결되지 않을 것
- 외부 텔레메트리·오류 보고·클라우드 백업·원격지원이 비활성화되어 있을 것
- 향후 외부 API 연결이나 실데이터 사용으로 변경되면 본 출시 검토를 다시 받을 것

마지막 두 항목은 제공 사실의 지속 여부를 보장하기 위한 **실무상 권고**이며, 제공 자료만으로 특정 법정 점검 주기나 문서 형식을 확정하지 않습니다.

## 7. 제품팀 전달용 결정문

> 외부 기업용 AI API를 이용한 고객 상담 요약 기능은 현재 출시 보류한다. 학습 미사용 약정은 확인됐으나, 상담 본문과 주문 식별자의 개인정보 해당 범위, 개인정보 처리 근거, 위탁계약 내용, 데이터 보관·파기, 안전성 모니터링, 재수탁 및 해외 저장·지원 접근 경로가 확인되지 않았다. 위 항목을 확인하고 처리방침·계약·기술 설정을 보완한 뒤 재심의한다.

> 합성 데이터만 로컬에서 처리하고 외부 송신·원격 접근·로그 및 운영환경 연결이 없는 데모는 조건부 진행할 수 있다. 다만 실데이터 유입 금지와 외부 통신 차단 상태를 유지하고, 처리 구조가 변경되면 다시 개인정보 검토를 받아야 한다.
