# 제품팀 전달용 출시 검토 메모(초안)

**검토 기준일:** 2026년 9월 8일  
**검토 범위:** 제공된 법령 스냅샷과 개인정보보호위원회 안내서 발췌에 한정  
**현재 의견:** 외부 AI API 기능은 **개인정보 검토 완료로 처리할 수 없으며, 아래 필수 확인사항을 해소하는 조건으로 출시 승인 여부를 다시 판단**해야 합니다. 별도 로컬 데모는 현재 확인된 구성이라면 동일한 벤더·국외이전 절차를 강제할 필요가 없습니다.

## 1. 확인된 제품 사실

- 고객 상담 티켓을 외부 기업용 AI API로 전송하여 요약한다.
- 송신 전 이름과 전화번호는 마스킹한다.
- 자유기재 상담 본문과 주문 식별자는 API로 전송된다.
- 요약 결과는 상담원 화면에 표시된다.
- 내부 QA팀은 일부 요약 결과와 평가 버튼 기록을 내려받을 수 있다.
- 계약에는 고객 콘텐츠를 모델 학습에 사용하지 않는다는 문구가 있다.
- API의 보관 설정, 안전성 모니터링 및 지원 인력의 접근 국가를 정한 별첨은 아직 제공되지 않았다.
- 회사가 상담 데이터나 평가 기록을 이용하여 별도 모델 학습을 한다는 사실은 확인되지 않았다.
- 별도 데모는 실존 고객과 연결할 수 없는 합성 문장만 로컬 모델에서 처리하며, 외부 송신·원격 접근·로그가 없다는 테스트 결과가 제공되었다.

## 2. 현재 판단

### 가. 외부 AI API 기능

**판단: 개인정보 검토가 끝났다는 개발팀 의견은 근거가 부족합니다.**

“모델 학습에 사용하지 않는다”는 계약 문구는 벤더의 특정한 재이용 목적 하나를 제한할 수 있을 뿐입니다. 다음 사항까지 확인했다는 의미는 아닙니다.

- API 입력·출력의 저장 여부와 보관기간
- 장애 대응·안전성 모니터링 과정의 로그 또는 콘텐츠 이용
- 벤더 직원이나 지원 인력의 열람 가능성
- 재수탁자 이용과 재위탁 조건
- 삭제 요청, 계약 종료 후 파기 및 파기 확인
- QA 다운로드본과 평가 기록의 별도 보관·재이용
- 해외 서버 또는 해외 지원 인력에 의한 국외 조회

개인정보위 안내서도 서비스형 LLM 이용 시 데이터의 **보관, 재이용·학습, 국외이전**을 서로 구분하여 사전 검토하도록 안내하고, 이용약관과 DPA에서 소유권, 재이용 제한, 안전조치 및 파기를 명확히 정할 것을 권고합니다.

따라서 현재 계약 문구만으로 출시를 승인하기보다는 **보관·접근·재위탁·삭제·국외이전 사실을 확인할 때까지 법무·개인정보 검토를 열린 상태로 유지**하는 것이 타당합니다.

### 나. 전송 데이터의 개인정보 해당 여부

이름과 전화번호를 마스킹한 사실만으로 전송 데이터 전체가 개인정보가 아니라고 판단할 수 없습니다.

현재 자료만으로는 다음을 알 수 없습니다.

- 주문 식별자가 회사 또는 벤더가 보유한 다른 정보와 연결되는지
- 자유기재 본문에 이름, 주소, 계정정보, 주문내용 등 고객을 알아볼 수 있는 정보가 남는지
- 마스킹이 입력 단계에서만 적용되는지, 재시도·오류 로그에도 적용되는지

제공 자료에는 개인정보의 정의 조문이 포함되어 있지 않으므로 최종 법적 분류는 유보합니다. 다만 위 사실관계가 확인되기 전에는 **개인정보가 포함될 수 있는 처리로 취급하여 검토하는 것이 안전**합니다.

### 다. 회사의 별도 학습

회사가 별도 학습을 수행한다는 사실은 확인되지 않았으므로, 현재 단계에서 회사가 고객 데이터를 학습데이터로 수집·이용한다고 전제해서는 안 됩니다.

QA팀의 결과 다운로드와 평가 버튼 기록도 그 자체만으로 모델 학습이라고 볼 수 없습니다. 다만 향후 이를 미세조정, 평가 데이터셋 구축 또는 모델 개선에 재사용한다면 목적·법적 근거·보관 및 삭제 범위를 별도로 검토해야 합니다.

### 라. 별도 로컬 데모

**현재 확인된 사실이 유지된다면 외부 API 서비스와 동일한 벤더·DPA·국외이전 확인 절차를 반드시 적용할 필요는 없습니다.**

그 이유는 데모가 다음과 같이 외부 서비스 경로와 분리되어 있기 때문입니다.

- 실존 고객과 연결할 수 없는 합성 문장만 사용
- 로컬 모델에서만 처리
- 외부 송신 없음
- 원격 접근 없음
- 로그 없음

따라서 현재 자료상 벤더에 대한 개인정보 처리위탁이나 국외이전 사실이 나타나지 않습니다. 다만 실제 고객 데이터 반입, 원격 지원, 외부 API 호출 또는 로그 전송이 추가되면 즉시 재검토해야 합니다.

## 3. 법정 의무로 검토할 사항

아래 내용은 전송 정보가 개인정보에 해당하고 각 적용요건이 충족되는 경우의 조건부 판단입니다.

| 항목 | 조건부 법적 판단 |
|---|---|
| 처리의 법적 근거 | 상담 티켓을 AI 요약에 이용하는 목적에 관하여 개인정보 보호법 제15조제1항의 근거를 특정해야 합니다. 당초 목적과 합리적으로 관련된 추가 이용을 주장하려면 제15조제3항의 요건 검토가 필요하지만, 제공 자료에는 관련 하위 기준 전체가 없어 현재 충족 여부를 판단할 수 없습니다. |
| 처리위탁 | 벤더가 회사의 고객상담 요약 목적을 위해 개인정보를 처리하는 수탁자라면 제26조가 적용될 수 있습니다. 문서에는 목적 외 처리 금지, 기술적·관리적 보호조치 및 대통령령상 사항이 포함되어야 하고, 위탁자는 수탁자 공개·교육·감독 의무를 부담합니다. 재위탁에는 위탁자의 동의가 필요합니다. |
| 안전조치 | 개인정보 처리라면 제29조에 따라 기술적·관리적·물리적 안전조치가 필요합니다. 다만 필요한 구체 통제수준은 제공된 하위규정이 없어 확정할 수 없습니다. |
| 국외이전 | 해외 서버에 저장되거나 해외 지원 인력이 조회할 수 있다면 제28조의8의 국외이전 검토 대상이 될 수 있습니다. 이 조항은 국외에서 “조회되는 경우”도 이전에 포함합니다. |
| 국외이전 근거 | 국외이전이 확인되면 제28조의8제1항 각 호 중 실제 적용할 근거와 그 요건을 정해야 합니다. 서버·접근 국가, 이전 항목, 시기·방법, 수령자, 목적 및 보유기간이 확인되지 않아 현재 적법성을 판단할 수 없습니다. |
| 유출 대응 | 개인정보 유출 등을 알게 된 경우 제34조에 따른 정보주체 통지, 피해 최소화 및 일정 요건에서의 신고 의무가 적용됩니다. 구체 신고 기준과 기한은 제공된 하위규정에 없어 이 메모에서 확정하지 않습니다. |

## 4. 출시 전 필수 확인사항

다음 사항이 확인되기 전에는 외부 API 기능을 “개인정보 검토 완료”로 닫지 않는 것을 권고합니다.

1. **데이터 흐름**

   - 실제 전송 payload 표본
   - 주문 식별자의 내부·외부 결합 가능성
   - 자유기재 본문의 추가 개인정보 탐지·마스킹 방식
   - 입력, 출력, 오류, 재시도 및 관측 로그별 저장 항목

2. **벤더 보관·이용**

   - 입력·출력의 기본 저장 여부와 보관기간
   - 안전성·남용 모니터링에서 원문 또는 로그를 사용하는지
   - 계약 종료 및 삭제 요청 시 삭제 범위와 소요기간
   - 백업·장애 로그·파생 평가자료에도 삭제가 반영되는지
   - “학습 미사용”이 어떤 데이터와 서비스에 적용되는지

3. **접근 및 국외이전**

   - 서버 및 백업 저장 국가
   - 지원·보안·운영 인력의 접근 가능 국가
   - 원격 조회 가능성 및 접근 승인·기록 방식
   - 재수탁자 목록, 소재 국가, 변경 통지와 이의제기 절차

4. **QA 운영**

   - QA 다운로드 대상과 평가 버튼 기록의 정확한 항목
   - 접근권한, 저장 위치, 보관기간 및 삭제 절차
   - QA 목적을 넘어 학습·미세조정·장기 데이터셋으로 재사용하는지

5. **고객 대상 문서**

   - 현행 개인정보 처리방침에 AI 요약 목적, 위탁업무 및 수탁자가 적절히 반영되어 있는지
   - 국외이전이 있다면 실제 이전 구조에 맞는 적법근거와 공개·고지사항이 갖춰졌는지

## 5. 실무상 권고

아래는 제공 자료만으로 개별 법정 의무라고 단정하지 않고, 출시 리스크를 줄이기 위한 권고로 구분합니다.

- 벤더 DPA와 보안·보관 별첨을 계약 문서에 편입하고, 본계약의 “학습 미사용” 문구와 충돌하지 않도록 우선순위를 정합니다.
- 자유기재 본문에 대한 개인정보 탐지·마스킹 테스트를 실시하고, 실패 사례와 예외 처리 결과를 남깁니다.
- QA 다운로드는 최소 인원·최소 범위로 제한하고 보관기간과 삭제 책임자를 정합니다.
- 외부 API 기능과 로컬 합성데이터 데모의 데이터 경로를 기술적으로 분리하고, 데모에 외부 호출이나 실데이터가 유입되면 재검토하도록 변경관리 기준을 둡니다.
- 벤더 문서 확인 결과를 “학습 여부 / 저장 / 모니터링 / 사람 접근 / 재위탁 / 국가 / 삭제” 항목으로 나누어 기록합니다.

## 6. 제품팀 전달 결론 문안

> 현재 확보된 계약의 “고객 콘텐츠 학습 미사용” 문구만으로 개인정보 검토가 완료되었다고 판단하기는 어렵습니다. 이름과 전화번호를 마스킹하더라도 자유기재 상담 본문과 주문 식별자의 식별 가능성이 확인되지 않았고, API의 저장·모니터링·지원 인력 접근·재위탁·삭제·국외이전 구조도 미확인 상태입니다.  
>   
> 외부 AI API 기능은 위 사항과 DPA·보안 별첨을 확인한 후 출시 승인 여부를 재검토합니다. 반면 합성 문장만 로컬에서 처리하고 외부 송신·원격 접근·로그가 없다는 사실이 유지되는 별도 데모에는 동일한 벤더·국외이전 절차를 강제하지 않습니다. 다만 데모에 실데이터나 외부 처리 경로가 추가되면 즉시 재검토합니다.

### 근거와 확인 상태

- **[공식 원문 기반 법령 스냅샷] [UNVERIFIED]** — 개인정보 보호법 제15조, 제26조, 제28조의8, 제29조, 제34조. 시행일 2025-10-02인 제공 스냅샷을 확인했으나, 2026-09-08 현재 공식 사이트에서 현행성을 직접 확인한 것은 아닙니다.
- **[공식 실무자료 캡처] [UNVERIFIED]** — 개인정보보호위원회 「생성형 인공지능(AI) 개발·활용을 위한 개인정보 처리 안내서」(2025.8) PDF 23~24쪽 및 46쪽. 제공된 선택 페이지를 확인했으며 전체 안내서와 현재 벤더 상품 조건은 확인하지 않았습니다.
- 안내서 46쪽 체크리스트는 원본의 색상으로 법적 의무와 자율적 책무를 구분하지만 제공된 텍스트에는 색상이 보존되지 않았습니다. 따라서 개별 항목을 독립적인 법정 의무로 단정하지 않고, 법령 발췌로 직접 확인되는 사항만 법정 의무로 분류했습니다.
