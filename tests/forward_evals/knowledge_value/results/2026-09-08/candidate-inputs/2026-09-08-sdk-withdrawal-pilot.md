광고·수집 UI를 껐거나 SDK·벤더가 acknowledgement를 보냈다는 사실만으로 전체 처리 중단을 추정하지 않는다. 외부 처리 경로가 있으면 UI off의 의미 → SDK 설정·초기화·버전 → server-side forwarding → 벤더의 처리 목적·대상 식별자·적용 시점·부분 실패·재활성화 조건 순으로 실제 흐름을 확인한다. `opt-out`, `suppression`, `delete`는 의미·범위·시점이 다를 수 있으므로 제품·벤더 원문으로 구별한다. 특정 SDK field, 로그 항목, 점검주기 또는 suppression SLA를 한국법상 범용 의무로 만들지 않는다. 개인을 식별하지 않는 anonymous aggregate만 내부 처리하고 광고 목적·외부 전송·외부 접근이 없다는 사실이 확인되면 vendor suppression, 국외이전, 광고 동의를 자동 쟁점화하지 않는다.
